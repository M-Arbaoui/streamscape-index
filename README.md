# Streamscape Index

Build a next-generation streaming platform web application for movies and TV series according to the attached PROJECT MASTER PROMPT and ADDITIONAL REQUIREMENT REAL METADATA SOURCES documents.

Follow Section 17 (First Task: Phase 1):
1. Build the visual foundation and cinematic homepage with rich dark surfaces, immersive hero section with backdrop artwork and metadata, navigation (Home, Discover, Movies, Series, Trending, My List, Search), and horizontal content discovery rows (Trending Now, Popular Movies, Popular Series, Top Rated, Continue Watching, By Genre).
2. Create interactive content cards with quick details, rating, year, watchlist action, and smooth transitions.
3. Structure the codebase with a modular foundation: separate content metadata (TMDB-aligned model) from playback services, and establish the multi-source provider abstraction & registry architecture so it's ready for provider integrations.
4. Use realistic mock content with rich artwork, synopses, cast, ratings, and genre tags.
